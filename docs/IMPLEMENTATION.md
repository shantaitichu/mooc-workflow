# 实施记录与验收边界

## 已落地

- Electron 安全隔离桌面界面，窄 IPC 白名单与本地素材协议；Node/文件系统不暴露给渲染页面。
- 按页课程、稳定页面 ID、三份讲稿文本、语义分段、停顿标记、读法词典、语速与页面覆盖设置。
- PPTX 页面关系/备注解析，PowerPoint 优先、LibreOffice 回退，PDF/图片本地渲染；替换课件前确认新旧页对应。
- 人物、声音、参考素材本地保存；按账号隔离的跨课程讲师库；动作生成入口与实拍动作导入、逐项验收及循环许可。
- 配音、视频、合成三级指纹与历史素材；改变语句只使对应段失效，历史工程设置可回退。
- 本地真实 FFmpeg 合成：四类版式、图片/视频背景、字幕、AI 提示标记、25fps 对齐、逐页缓存和最终拼接。
- MP4、SRT、WAV、章节表、逐页视频、可恢复工程包；字幕烧录切换仅做本地重渲染。
- 云端作者/管理员、组织钱包、事务冻结/结算/退款、幂等提交与充值、预算检查、素材所有权隔离。
- 云端持久任务与客户端恢复查询、不确定受理状态隔离、临时输入/结果清理、可选私有 S3 与 PostgreSQL。
- 百炼 HTTP 音色复刻/查询/删除/TTS、MediaKit 口型、国内火山 Dreamactor/OmniHuman 直连代码；未提供密钥或未验收时明确不可用。
- 云任务列表与结果到期时间、动作/音色恢复入库、完整账单 CSV；报价扣除缓存并显示语音/人物分项。

## 当前限制，不能视为已验收能力

| 项目 | 当前边界 |
| --- | --- |
| 真实生成效果 | 无真实讲师素材或服务凭据，未验证音色相似度、口型 ≤100ms、自然动作和供应商最终账单 |
| Dreamactor / OmniHuman | 直连签名、模型各自提交/查询协议及异常处理已实现，签名已对照官方 SDK 固定向量验证；未作真实付费调用，五段参考动作参考需平台提供 |
| 复杂人像抠图 | 讲师照片接入 MediaKit 人像背景移除，结果保存为 PNG |
| 自动质量检测 | 已有文件/时长/分辨率检查；未接入 ASR 漏读检查、语音强制对齐、脸部/手部质量模型 |
| 字幕精度 | 边界使用实际音频段时长，段内按文本长度分配，不是词级强制对齐；正式导出需人工核对 |
| 气口精度 | SSML 与本地帧边界填充已实现；尚未实现生成后逐停顿检测 / 静音边界自动修正，也不自动伪造呼吸音 |
| 多机构生产 | 数据与权限结构已建立；PostgreSQL/S3/多实例负载与机构安全上线验收未在本机运行 |
| 长课 | 已通过 100 页、60 分钟合成时序压力测试，实测 3,600.021 秒、90,000 帧；使用合成素材，真实人物的整课自然度与模型调用质量尚未验收 |
| 云端删除 | 临时对象清理、持久音色删除接口与本地入口已实现；供应商侧删除尚未实测，机构注销级清理未完整接入 |
| 合成内容标识 | 有可见 AI 提示与来源元数据；尚未完成适用强制标准的字段/封装与传播平台验收 |
| 素材预检 | 已有格式、音轨、采样率、分辨率、时长检查；多人/噪声/混响/脸部与手部遮挡分析需后续检测模型 |
| 工程包 | 含素材、设置、音色身份摘要、字幕时间线和重合成缓存；当前 ZIP 恢复限制单包 2GB，较大工程需备份工程目录 |
| 动作编排 | 可逐页指定动作并验收循环；自动跨句选择动作、避免连续重复和精确姿态过渡尚未实现 |
| 其他编辑功能 | 当前可用文字气口和页级覆盖；逐段独立语速、从参考视频截帧 / 提取声音、单句只试听而不继续视频生产、课件重点高亮、片头片尾专用模板尚未完整实现 |
| 运营监控 | 有持久任务状态与产品账单；供应商账单对账、运营成本统计、告警和多实例压力指标待接入 |
| 发行包 | 已构建并启动验证未签名 Windows x64 程序及 NSIS 试用安装包；正式代码签名与品牌安装资源需要发行方配置 |

## 验证方法

所有自动化测试素材均为自建文字/纯色/测试音，不冒充真人数字人效果。媒体测试实际调用 FFmpeg 并用 FFprobe 验证帧率、尺寸、时长、音轨和导出文件。桌面测试实际启动 Electron，而非仅测试浏览器 Mock。

生产开放顺序：补齐真实凭据与试点素材 → 按视觉网关文档完成模型验收 → 录入已验收模型清单 → 小范围机构试点 → 完成上表剩余上线项。
